# campus-social-map
📍 Campus Social Map
An interactive, real-time social networking platform designed for university campuses. This application helps students navigate their campus while discovering academic and social opportunities in real-time.

🚀 Overview
Campus Social Map bridges the gap between physical campus locations and digital social interactions. Whether it's a spontaneous group study session in the library or a major hackathon in the auditorium, students can find, tag, and join events instantly.

✨ Key Features
Interactive Campus Map: Visual exploration of campus landmarks and real-time event hotspots.

Event Discovery System: Seamlessly browse through categories like Group Studies, Club Events, Hackathons, and Workshops.

Location Tagging: Users can pin specific events to exact campus coordinates for easy navigation.

Personalized Activity Feeds: Stay updated with a curated feed based on your interests and followed clubs.

Real-Time Updates: Discover what is happening now to ensure you never miss out on campus life.

🛠️ Tech Stack
Frontend: React.js, Vite

Backend: Node.js, Express.js

Database: MongoDB

Styling: Tailwind CSS (or your chosen CSS framework)

Authentication: JWT & BCrypt for secure user sessions
